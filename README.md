# 十八单词

高中英语词汇记忆工具。数据来自《人教版（2019新课标）高中英语词汇表》（必修第一~三册 + 选择性必修第一~四册，共 7 册 36 个单元、2552 个词条）。

## 目录结构

```
十八单词/
├── 十八单词.py          # 主程序（入口）
├── icon.ico             # 程序图标
├── README.md
└── dev_english/         # 词库目录：一个 .json 就是一个词库
    ├── 必修第一册.json
    ├── 必修第二册.json
    ├── 必修第三册.json
    ├── 选择性必修第一册.json
    ├── 选择性必修第二册.json
    ├── 选择性必修第三册.json
    └── 选择性必修第四册.json
```

## 运行

需要 Python 3 和 wxPython（Phoenix 版）：

```bash
pip install wxPython
cd 十八单词
python 十八单词.py
```

程序启动后：

- 菜单 **文件 - 编辑 - 配置词库**：勾选本次要学习的词库，点“确定”生效，点“取消”不改动；
- 菜单 **文件 - 退出(Alt+F4)**：关闭程序；
- 主界面显示当前已选词库及合计词数；
- 运行日志写入同目录下的 `debug.txt`。

路径都基于脚本所在目录，从任何位置启动都能正确找到 `icon.ico` 与 `dev_english/`。

## 词库格式

每个词库文件是一个 JSON 对象，按册组织、册内按单元、单元内按原表顺序排列：

```json
{
  "词库名称": "必修第一册",
  "来源": "人教版（2019新课标）高中英语词汇表",
  "单元": [
    {
      "单元名称": "Welcome Unit",
      "单词": [
        {
          "单词": "exchange",
          "音标": "/ɪksˈtʃeɪndʒ/",
          "词性": "n./vt.",
          "释义": "交换；交流；交易；兑换"
        }
      ]
    }
  ]
}
```

程序用**文件名（去掉 .json）**作为词库名，因此新增词库只需往 `dev_english/` 里放一个 JSON 文件即可，无需改代码。

## 相对原代码的改动

原代码基于 wxPython 2.x（Classic）写法，在当前的 wxPython Phoenix 下无法运行，做了以下修正：

| 位置 | 原写法 | 现写法 |
| --- | --- | --- |
| 编辑菜单 | `menuEdit.AppendItem(item)` | `menuEdit.Append(id, label)` |
| 子菜单 | `menuFile.AppendMenu(EDIT_MENU, "编辑", menuEdit)` | `menuFile.AppendSubMenu(menuEdit, "编辑")` |
| 退出项 | `menuFile.AppendItem(quitMenu)` | `menuFile.Append(QUIT_MENU, "退出(Alt+F4)")` |
| 图标 | `SetIcon(icon=wx.Icon(...))` | `SetIcon(wx.Icon(path, wx.BITMAP_TYPE_ICO))` |

其他调整：

- 词库列表、按钮改用 **Sizer 布局**，词库多时放入滚动窗口，勾选框不会再被挤出可视区；
- “确定 / 取消” 用 `ShowModal()` 返回值区分，**取消不再误改选择**，确定则保存勾选结果；
- 启动时扫描 `dev_english/`，菜单里显示每个词库的词条数；
- 主界面增加一行状态文字（已选词库 + 合计词数）；
- 所有路径改为相对脚本目录，避免换工作目录后找不到文件；
- 文件读写统一指定 `utf-8`，避免中文在非 UTF-8 默认编码的机器上乱码。
